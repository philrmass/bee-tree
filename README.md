# Bee Tree
by Phil Mass

## Description
A project to solve the NY Times Spelling Bee puzzle using a trie data structure

## Usage
Requires Node 20.19+ (or 22.12+).

```sh
npm install    # install dependencies
npm run dev    # development: server on port 2323, app on http://localhost:2324
npm start      # production: build, then serve the app on http://localhost:2323
```
